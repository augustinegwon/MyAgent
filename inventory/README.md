# 📦 회사 물품 인벤토리 관리 시스템 (Google Sheets + Apps Script)

물품별 **물품명 · 시리얼번호 · 수량 · 위치 · 상태(정상/고장/수리중)** 를 관리하고,
물품 이동을 **날짜(타임스탬프) · 수량 · 재고 변화 · 이동 장소** 까지 자동으로 기록하는
스프레드시트입니다. 마스터 대시보드는 자동 집계되며 편집이 잠겨 있습니다.

---

## 1. 시트 구성

| 시트 | 표시 | 역할 |
|------|------|------|
| **마스터** | ✅ | 물품별 × 위치별 수량, 물품당 총합, 상태(정상/고장/수리중) 요약. **자동 생성·편집 금지(보호됨)** |
| **물품편집** | ✅ | 물품 등록/이동/상태변경/수량조정을 입력하는 폼 + 선택 물품의 현재고·이력 조회 |
| **이동로그** | ✅ | 모든 변화가 타임스탬프와 함께 append 되는 이력 로그 |
| `재고원장` | 🙈 숨김 | 현재고의 단일 진실원본(Source of Truth). 마스터/조회의 계산 근거 |
| `_목록` | 🙈 숨김 | 드롭다운(물품명·위치)용 자동 목록 |

> 마스터·이동로그·물품편집 3개가 실제로 사용하는 화면이고, 숨김 2개는 엔진입니다.

---

## 2. 데이터 모델 — 두 가지 관리 유형

| 유형 | 고유키 | 수량 | 예시 |
|------|--------|------|------|
| **시리얼관리** | 시리얼번호 (전역 고유) | 항상 **1** | 노트북, 모니터 등 자산 |
| **수량관리** | (물품명 + 위치 + 상태) | **1개 이상** | A4용지, 마우스 등 소모품 |

- 시리얼관리 물품은 시리얼 하나가 곧 물품 1개이며, 위치·상태는 그 시리얼의 현재 속성입니다.
- 수량관리 물품은 같은 위치라도 상태별(정상/고장/수리중)로 수량이 나뉘어 관리됩니다.

---

## 3. 설치 방법 (5분)

1. Google Drive에서 새 **Google 스프레드시트** 생성
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 **`Code.gs`** 전체를 붙여넣기 → 저장(💾)
4. 스프레드시트로 돌아와 **새로고침**(F5) → 상단에 **📦 인벤토리** 메뉴가 생김
5. **📦 인벤토리 → ⚙️ 초기 설정(시트 생성)** 클릭
   - 최초 실행 시 권한 승인 창이 뜨면 본인 계정으로 허용
6. (선택) **📦 인벤토리 → 🧪 샘플 데이터 넣기** 로 동작 확인

> `appsscript.json` 은 시간대(Asia/Seoul)·런타임 설정입니다. Apps Script 편집기에서
> ⚙️(프로젝트 설정) → "`appsscript.json` 매니페스트 표시" 를 켜면 이 파일도 편집할 수 있습니다.

### (선택) 버튼 만들기 — "편집 적용" 버튼

메뉴 대신 시트 위 버튼을 쓰고 싶다면:

1. **물품편집** 시트에서 **삽입 → 그림** → 도형/텍스트로 `✅ 편집 적용` 버튼을 그린 뒤 저장
2. 삽입된 그림 우측 상단 **⋮ → 스크립트 할당** → `applyEdit` 입력
3. 같은 방식으로 `🔍 조회` 버튼을 만들어 `lookupItem` 할당

## 4. 사용법

**물품편집** 시트 상단 폼(B열)에 값을 채우고, **📦 인벤토리 → ✅ 편집 적용**(또는 버튼) 을 누릅니다.
물품명을 고르면 아래 **📋 조회 결과** 에 현재고와 **📜 최근 변경 이력** 이 자동으로 표시됩니다.

작업유형별 필요한 값:

| 작업유형 | 필요한 값 | 결과 |
|----------|-----------|------|
| **신규등록** | 물품명, 관리유형, (시리얼 또는 수량), 출발위치, 상태 | 원장에 재고 추가 · 로그 `입고` |
| **재고이동** | 물품명, 관리유형, 출발위치, 도착위치, (시리얼 또는 수량), 상태(옮길 상태) | 출발↓/도착↑ · 로그 `이동`(출발·도착 재고 기록) |
| **상태변경** | 물품명, 관리유형, 출발위치, (시리얼 또는 수량), 상태(변경 전→후) | 상태 전환 · 로그 `상태변경` |
| **수량조정** | 물품명, 수량관리, 출발위치, 수량(실사 최종값), 상태 | 실사 보정(절대값 설정) · 로그 `수량조정` |

### 예시 — 노트북 2대를 본사창고 → 강릉지사로 이동
> 시리얼관리 물품은 1대씩 이동합니다. 아래를 시리얼별로 2번 실행.

```
작업유형    = 재고이동
물품명      = 노트북 ThinkPad X1
시리얼번호  = SN-LT-001
관리유형    = 시리얼관리
출발위치    = 본사창고
도착위치    = 강릉지사
상태(변경전)= 정상
→ ✅ 편집 적용
```

### 예시 — A4용지 30박스를 본사창고 → 강릉지사로 이동
```
작업유형    = 재고이동
물품명      = A4 복사용지
관리유형    = 수량관리
출발위치    = 본사창고
도착위치    = 강릉지사
수량        = 30
상태(변경전)= 정상
→ ✅ 편집 적용
```
로그에 `타임스탬프 / 이동 / 30 / 본사창고 → 강릉지사 / 출발지 이동후재고 20 / 도착지 이동후재고 50` 이 남고,
마스터의 해당 위치별 수량과 총합이 즉시 갱신됩니다.

---

## 5. 이력 조회 (타임스탬프 기반)

- **특정 물품**: 물품편집 시트에서 그 물품명을 선택하면 현재고 + 최근 10건 이력이 자동 표시됩니다.
- **전체/기간별**: **이동로그** 시트 상단에서 **데이터 → 필터 만들기** 로 `물품명`·`작업유형`·기간을 필터링하세요.
- 원장(`재고원장`)의 `최종수정일`, 로그의 `타임스탬프` 로 언제 무엇이 바뀌었는지 추적됩니다.

## 6. 메뉴 요약

| 메뉴 | 함수 | 설명 |
|------|------|------|
| ⚙️ 초기 설정(시트 생성) | `setup` | 시트·헤더·드롭다운·보호 일괄 생성 (최초 1회) |
| 🔍 물품 조회 | `lookupItem` | 선택 물품의 현재고·이력 표시 |
| ✅ 편집 적용 | `applyEdit` | 폼 내용을 원장/로그/마스터에 반영 |
| 🔄 폼 초기화 | `clearForm` | 입력·조회 영역 비우기 |
| 📊 마스터 새로고침 | `rebuildMaster` | 마스터 재집계(수동 갱신) |
| 🧪 샘플 데이터 넣기 | `loadSample` | 예시 데이터 로드 |

---

## 7. 동작 방식(요약)

```
[물품편집 폼] --applyEdit--> [재고원장(현재고)] --집계--> [마스터(편집금지)]
                    |
                    +--append--> [이동로그(타임스탬프 이력)]
```

- 모든 변경은 **원장(현재값)** 과 **로그(이력)** 에 동시에 기록됩니다.
- 마스터는 원장을 다시 집계해 그려지고(`rebuildMaster`) 시트 보호로 편집이 잠깁니다.
- 물품명/위치 드롭다운은 원장 기준으로 자동 갱신되며, 새 값은 직접 입력해 추가할 수 있습니다.

---

## 8. 주의 / 한계

- 마스터는 편집 시 자동 반영되지만, 원장을 손으로 고쳤다면 **📊 마스터 새로고침** 을 눌러야 합니다.
- 여러 명이 동시에 편집하는 대규모 환경에서는 동시성 충돌 방지를 위해 편집 담당자를 지정하는 것이 안전합니다.
- 시리얼관리 물품 이동은 1개 단위입니다(수량 필드 무시, 항상 1).
